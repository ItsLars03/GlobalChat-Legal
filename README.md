## 🤖 About GlobalChat

GlobalChat allows Discord servers to connect selected channels to shared global chat categories such as English chat, Dutch chat, German chat, Spanish chat, French chat, anime, cooking, politics, gaming and more.

Server administrators choose which channels are connected. Messages sent in connected channels can be relayed to other connected servers in the same category.

## ⚙️ Setup Commands

| Command | Description |
|---|---|
| `/help` | Shows the help menu. |
| `/language` | Choose the bot language for your server. |
| `/categories` | View available global chat categories. |
| `/add` | Connect the current channel to a global chat category. |
| `/delete` | Disconnect the current channel from GlobalChat. |
| `/format` | Choose between embed style or webhook style. |
| `/leaderboard` | View the most active GlobalChat users. |
| `/support` | Shows support/contact information. |
| `/report` | Report a user/message to the bot owner. |

## 🛡️ Moderation Commands

Some commands are only available to the bot owner or assigned GlobalChat moderators.

| Command | Description |
|---|---|
| `/ban` | Ban a user from the global chat network by user ID. |
| `/unban` | Remove a global ban from a user. |
| `/mute` | Temporarily mute a user from GlobalChat. |
| `/unmute` | Remove a global mute from a user. |
| `/purge` | Delete messages from linked GlobalChat channels. |
| `/announcement` | Send a global announcement to connected channels. |
| `/addmods` | Add a GlobalChat moderator. |
| `/removemod` | Remove a GlobalChat moderator. |
| `/blacklist` | Blacklist a server from using GlobalChat. |
| `/unblacklist` | Remove a server from the blacklist. |
| `/blacklistlist` | View blacklisted servers. |
| `/serverlist` | View servers using the bot, including invite links where available. |
| `/connections` | View which channels are connected to which global chat categories. |

## 🔐 Privacy & Safety

GlobalChat only processes messages in channels that server administrators explicitly connect to a global chat category.

GlobalChat does not sell user data, does not use message content for advertising, and does not use message content to train AI or machine learning models.

Safety features include:

- Link blocking
- Forbidden-word filtering
- Global mutes and bans
- Server blacklisting
- User reports
- Moderator tools

# Privacy Policy

GlobalChat only processes messages sent in Discord channels that server administrators have connected to a GlobalChat category.

The bot may process message content, user IDs, server IDs, channel IDs, usernames, avatars, attachments and moderation/report information in order to relay messages between connected servers, provide moderation tools, block unsafe content and handle reports.

GlobalChat does not sell user data, does not use message content for advertising, and does not use message content to train machine learning or AI models.

Message content is not stored permanently by the bot unless it is included in moderation logs, reports or required operational records. Server administrators can disconnect a channel at any time.

For support or data questions, contact: itzjustlars on Discord.
